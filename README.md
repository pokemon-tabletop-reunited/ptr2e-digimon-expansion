# ptr2e-digimon-expansion
Expansion Module for the [PTR2e system](https://github.com/pokemon-tabletop-reunited/ptr2e) adding Digimon and their associated content to the game!

You can install this module using the following Manifest URL: (Once it has released)
```json
https://github.com/pokemon-tabletop-reunited/ptr2e-digimon-expansion/releases/latest/download/module.json
```
